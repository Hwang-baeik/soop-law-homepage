# 법인설립 기초조사서 운영

`/incorporation`은 제공된 주식회사 설립등기 기초조사서의 회사 기본정보, 목적, 임원, 주주, 전자증명서 희망사항을 입력받는다. 홈페이지 첫 화면과 문의메일 페이지에 진입 링크를 둔다. 담당자 성함·이메일·연락처 이외에는 미정으로 표시하거나 비워둘 수 있다. 원본의 기본값은 사용자가 선택한 경우에만 적용한다. 비어 있는 항목은 전송 전 확인과 메일에서 미정으로 정리된다.

주민등록번호, 생년월일, 개인 주소, 계좌번호와 비밀번호를 입력받는 필드는 두지 않는다. 주민등록번호 형태가 자유입력에 포함되면 거부한다. 정보 제공 권한과 개인정보 수집·이용 동의를 확인하고, 동의 안내 버전 incorporation-v3을 메일에 기록한다. 내용은 브라우저 저장소나 사이트 DB에 저장하지 않고 사무소 메일로만 전달한다. 미리보기 후 전송하며 실패 시 화면의 입력 내용을 보존한다.

## 메일

기존 Vercel Production/Preview에 등록된 `RESEND_API_KEY`를 사용한다. 발신자는 `contact@sooplaw.com`, 수신자는 서버에서 고정한 `soop@sooplaw.com`, 회신 주소는 담당자 이메일이다. Resend에서 해당 발신 도메인의 인증을 유지해야 한다. 일반 텍스트로 보내며 사용자 입력을 HTML로 실행하지 않는다. 메일 본문과 완료 화면에 같은 접수번호를 표시한다.

동일한 정규화 내용은 같은 Resend Idempotency-Key를 사용한다. 요청 ID를 바꾸거나 서버 인스턴스가 바뀌어도 같은 메일 내용을 24시간 이내 재전송하는 경우 메일 서비스가 중복을 억제한다. 이 보호는 Resend의 키 보존기간에 한정된다. 제공자가 발송 접수를 확인해야만 완료 응답을 보낸다. 받은편지함 도착이나 담당자 확인까지 보장하는 표시는 하지 않는다.

## 보호장치

`instrumentation-client.ts`와 `next.config.ts`에서 `/api/incorporation`, `/api/contact` POST에 BotID를 설정하고 서버에서 `checkBotId()`를 실행한다. 양쪽 모두 **basic** 모드를 명시한다. 별도 CAPTCHA 키나 유료 Deep Analysis는 사용하지 않는다. 로컬에서는 BotID 자체 기본 동작이 봇 아님으로 반환되므로 로컬 통과가 운영 검증의 증거는 아니다. 운영에서는 일반 브라우저 제출과 인증 없는 자동 POST 차단을 별도로 확인한다. 인증 서비스의 오류는 접수를 차단하며 우회해 발송하지 않는다.

서버에서 동일 Origin, JSON 형식, 숨김 필드, UUID, 입력 길이·형식·개인정보 동의를 검사한다. 요청 본문은 조사서 48 KiB, 기존 상담문의 32 KiB를 스트림에서 제한하고, 본문 수신은 8초, 외부 메일 요청은 12초, 브라우저 요청은 30초에 제한한다. 지분율은 확정된 경우 합계 100%를 검사하고 미정 지분은 허용한다.

메모리를 제한한 보조 횟수 제한을 적용한다. **서버 인스턴스별** 동일 IP 시도 20회/10분, 메일 발송 시도 5회/10분, 인스턴스 전체 시도 1,000회/분 및 메일 발송 시도 50회/시간·200회/일이다. 한도 초과는 429로 응답한다. IP는 Vercel의 공식 ipAddress 헬퍼로 읽고 해시하며 메모리에만 유지한다. 카운터 수는 최대 2,048개이며 만료 시 정리한다. 서버 재시작·확장·지역 분산을 넘는 전역 한도는 아니다. 분산 공격의 정확한 전체 발송 상한이 필요하면 공유 저장소 기반 제한을 추가해야 한다.

기존 Vercel 기본 DDoS 보호는 유지한다. 별도 WAF 규칙·Attack Mode·유료 서비스는 이 변경에서 활성화하지 않는다. BotID basic은 모든 정교한 자동화나 네트워크 포화 공격에 대한 완전한 방어를 보장하지 않는다.

## 검증

- `npx tsc --noEmit`
- `node --test tests/*.test.mjs`
- `npm run build`

새 테스트는 실제 TypeScript 폼 검증·공통 보호·API 코드를 실행한다. BotID와 메일 응답만 모의 처리하므로 실제 메일을 발송하지 않는다. 소스의 기본 검증과 기존 회원·회사 기능 회귀 테스트를 함께 실행한다. 실제 메일 수신과 운영 브라우저에서의 BotID 통과는 별도 검증 항목이다.
