# 법인설립 기초조사서

`/incorporation`의 조사서는 `POST /api/incorporation`으로 접수한다. 기존 문의와 같은 Resend 설정 및 사무소 수신 주소를 사용한다. 서버에서 접수 내용을 텍스트 메일로 정리하며 담당자의 이메일을 회신 주소로 설정한다. 동일한 내용의 재시도에는 Resend의 중복 전송 방지 키를 재사용한다. 발송 서비스가 요청을 접수한 뒤 접수번호를 표시한다.

## 국문상호 표기

신청인이 선택한 위치에 회사 종류를 붙여 1순위와 2순위 국문상호를 표시한다. 전송 전 미리보기와 사무소 메일에도 완성된 국문상호를 사용한다.

## 사업목적 분류

제11차 한국표준산업분류의 대분류 21개에서 3자리 소분류 234개, 4자리 세분류 501개, 5자리 세세분류 1,205개를 각각 선택할 수 있다. 미리보기와 접수 메일에는 선택된 코드와 해당 분류의 공식 명칭을 표시한다.

- [한국표준산업분류 제11차 개정 고시와 분류 항목표](https://mods.go.kr/board.es?act=view&bid=107&list_no=428660&mid=a10403040000)
- [한국표준산업분류 제11차–제10차 연계표](https://mods.go.kr/board.es?act=view&bid=107&list_no=430619&mid=a10403040000)

## 접수 보호

동일 출처와 JSON 형식, 48 KiB 본문 제한, 숨김 입력란, 동의 및 항목별 검증을 적용한다. 서버 인스턴스마다 10분에 IP당 최대 12회, 전체 접수 시도 최대 180회, 메일 발송 시도 최대 25회로 제한한다. 인스턴스가 분리되거나 재시작하면 횟수도 각각 집계된다.
